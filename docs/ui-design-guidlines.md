CSP UI Design Guidelines

1. UI Framework
   - React + TypeScript
   - MUI is the primary component library.

2. Design Principles
   - Follow Material Design principles where applicable.
   - Favor clarity, hierarchy, consistency, accessibility, and
     efficient information density appropriate for a business application.

3. Component Usage
   - Prefer MUI components over custom equivalents.
   - Follow MUI recommended usage and accessibility patterns.
   - Create custom components only when the application requires
     behavior not adequately supported by MUI.

4. Application Patterns
   - Navigation
   - Forms
   - Tables/queue views
   - Case detail
   - Status/priority indicators
   - Notifications
   - Dialogs
   - Validation/errors

5. Responsive Behavior
   - Desktop-first business application.
   - Support common desktop browser sizes.
   - Adapt reasonably to smaller screens.

6. Accessibility
   - Use accessible MUI components and keyboard interaction.
   - Do not rely solely on color to communicate state.
